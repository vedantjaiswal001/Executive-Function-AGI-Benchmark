# Executive Function Benchmarking for AGI

## Overview
This project was developed for the Kaggle × Google DeepMind hackathon:

**“Measuring Progress Toward AGI – Cognitive Abilities”**

The benchmark focuses on evaluating **Executive Functions** in AI systems and Large Language Models (LLMs). The goal is to measure how effectively models can plan, adapt, inhibit impulsive responses, switch rules, and maintain working memory under cognitive load.

---

## Cognitive Abilities Evaluated

### 1. Inhibitory Control
Tests whether models can suppress habitual or impulsive responses when task rules change.

### 2. Cognitive Flexibility
Evaluates the ability of models to adapt dynamically between changing objectives and reasoning strategies.

### 3. Rule Switching
Measures how effectively models transition between multiple task rules without perseverative errors.

### 4. Working Memory
Assesses the ability to retain and manipulate information during multi-step reasoning tasks.

## Objectives
This benchmark aims to provide deeper insights into executive cognitive capabilities in AI systems by evaluating:

- Adaptive reasoning
- Task planning
- Memory retention
- Behavioral control
- Dynamic decision-making

The project is designed to move beyond traditional accuracy-based evaluations and analyze how models behave under cognitively demanding scenarios.
